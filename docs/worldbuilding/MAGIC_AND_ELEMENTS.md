# 魔法与元素

[世界观入口](README.md) · [待定事项](OPEN_QUESTIONS.md#魔法与元素)

## 魔法来源与契约

世界之树的根脉能够提供魔法。普通生物若想使用某种元素的魔法，需要与对应的元素泰坦签订契约。

生物使用契约魔法越多，对应元素泰坦积累的力量越多；这些力量能够使泰坦恢复元气，甚至复活。

契约形式、学习方式、使用代价与复活条件尚未确定。这是世界观设定，尚未转化为游戏数值机制。

## 元素泰坦

世界存在十种元素，每个星球原本各有对应的十位元素泰坦守护。决战经过见 [历史时间线](HISTORY.md#时间线)。

| 元素 | 泰坦 | 决战后的状态 |
|---|---|---|
| 水 | 水之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 火 | 火之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 土 | 土之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 电 | 电之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 风 | 风之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 冰 | 冰之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 木 | 木之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 光 | 光之泰坦 | 存活，但元气大伤 |
| 暗 | 暗之泰坦 | 存活，被赶走，正在谋划复仇 |
| 无 | 无之泰坦 | 被光之泰坦杀死，能量被夺取 |

## 能量关系

水、火、土、电、风、冰、木、无八位泰坦依赖光之泰坦的能量；暗之泰坦不依赖它。依赖的成因、表现与代价未定。

光之泰坦夺取了八位已死泰坦的元素能量，但仍元气大伤。

玩法中的十元素标识及卡牌分类见 [游戏设计](../design/GAME_DESIGN.md#元素属性)。世界观中的契约与泰坦恢复不直接等同于战斗中的魔法消耗、再生或属性克制机制。
