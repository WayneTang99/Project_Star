## 纪年

人们以泰坦决战发生年为标准元年，称为“泰坦光复年”，简称 `TR`。决战年记为 `TR1`（泰坦1年），此后依次为 `TR2`、`TR3`……

无法确定具体年份的早期事件记为“不可考”；仅确认先后关系的事件记为“TR1之前／之后”，确认年份后再更新。

## 时间线

| 年份 | 已确认事件与结果 |
|---|---|
| 不可考 | 创星者创造星球，创造年份已不可考 |
| 不可考 | 人类自然演化为智慧生物，演化过程与形成文明的年份不可考 |
| TR1之前 | 每个星球原本由水、火、土、电、风、冰、木、光、暗、无十位元素泰坦共同守护 |
| TR1之前 | 光之泰坦利用其他八位泰坦对自己能量的依赖，以对抗暗之泰坦为名威胁他们结盟，形成九位泰坦的联盟 |
| TR1 | 九位结盟泰坦对抗暗之泰坦；光之泰坦背叛盟友，杀死其他八位泰坦并夺取能量，随后赶走暗之泰坦；自身元气大伤，十泰坦守护体系瓦解 |
| TR1之后，年份待定 | 光之泰坦因惧怕暗之泰坦复仇而创立光明教会，让人类代替自己与暗元素对抗 |
| TR1之后，年份待定 | 光明教会启用世界树与根脉网络，在十个已知地区间传送兵力并维持控制 |
| TR1之后，年份待定 | 暗之泰坦开始复仇计划：摧毁全部世界树，切断光之泰坦的传送与控制网络，逼其现身并复仇 |

## 当前局势

光之泰坦尚未完全恢复，暗之泰坦仍在谋划复仇。冲突通过世界树网络和人类军队延续。

教会及其控制网络见 [地区与势力](WORLD.md#光明教会与城邦)，泰坦当前状态与恢复途径见 [魔法与元素](MAGIC_AND_ELEMENTS.md#元素泰坦)。
