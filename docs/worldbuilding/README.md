# 世界观

这里维护已确认的世界设定与待定问题。世界观是叙事依据；具体玩法和数值以 [游戏设计](../design/GAME_DESIGN.md) 为准。

## 核心脉络

创星者创造星球，十位元素泰坦曾共同守护它。泰坦决战中，光之泰坦背叛并杀死八位盟友、夺取他们的能量，赶走暗之泰坦，自身也元气大伤。

光之泰坦建立光明教会，操控人类心智，借助十一棵世界树的根脉网络调动军队。暗之泰坦计划摧毁世界树、切断网络，逼其现身复仇。

根脉同时提供魔法。普通生物与对应元素泰坦签约后使用魔法；施法使对应泰坦积累力量，能够恢复元气甚至复活。

## 维护约定

- 用户确认的设定直接写入所属专题；本页只保留必要摘要，不复制详细规则。
- 同一事实只在一个专题完整维护，其他专题用链接引用；事件归历史、当前组织与地理归地区与势力、魔法机制归魔法与元素。
- 未确认的问题和灵感集中写入待定事项，不能混入正式设定；确认后迁入专题并删除对应待定项。
- 不保留已迁入专题的灵感副本或空白大模板，修订与废弃内容由 Git 历史保存。
- 世界观修改不自动授权玩法或数值改动；出现冲突先记录待定问题，再由用户确定。
