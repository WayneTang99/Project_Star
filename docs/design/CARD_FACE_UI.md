# 卡牌卡面 UI

卡牌正面由 `CardFace.tscn` 统一绘制。卡牌身份、等级、原画、属性、效果和价值通过只读 `CardFaceViewModel` 提供；场景只负责排版与显示，不改动卡牌或战斗状态。

## 固定版式

以高度 400 为基准，各尺寸维持同高：

| 尺寸 | 卡面宽 × 高 | 比例 |
|---|---:|---:|
| 小型 | 200 × 400 | 1:2 |
| 中型 | 400 × 400 | 1:1 |
| 大型 | 600 × 400 | 3:2 |

- 顶部：卡名居中；等级菱形徽记使用等级颜色（1 银灰、2 蓝、3 紫、4 橙、5 红），不额外写等级文字。
- 中部：原画铺满画框，按卡面窗口裁切。
- 原画与底栏交界处：属性徽章组以卡面水平中心为锚点，压在分界线上。单属性正中，多属性以 4px 间隔组成整体后居中。通用属性用银灰圆徽，不加光芒。
- 底栏左侧：伤害、治疗、护甲、中毒、灼伤按传入顺序从左下角向上堆叠；效果多时允许盖到原画。
- 底栏右侧：价值图标和当前价值，靠右下对齐。
- 不显示冷却、描述、标签等其他字段。

外框、字体色和布局对所有卡牌相同。归属只轻微调整边框细线与装饰色；不改变信息位置、字号、徽章大小或原画窗口结构。

## 模块

| 模块 | 职责 |
|---|---|
| `CardFace.tscn` / `CardFace.cs` | 组合各子模块，按 `CardSize` 设置宽度，统一高度和锚点 |
| `CardFaceViewModel.cs` | 卡面所需只读字段，供内容层或 ViewModel 适配器创建 |
| `CardLevelGem.tscn` / `CardLevelGem.cs` | 只用颜色表示等级 |
| `CardElementBadge.tscn` / `CardElementBadge.cs` | 显示单个属性徽章；元素组的位置由卡面统一居中 |
| `CardEffectRow.tscn` / `CardEffectRow.cs` | 一个效果图标和数值，可按数据重复排列 |
| `CardValueBadge.tscn` / `CardValueBadge.cs` | 价值图标和数字 |

新增卡牌时传入该卡的尺寸、等级、归属、原画、属性、效果数值和当前价值，然后调用 `CardFace.SetCard(viewModel)`；不复制卡框或重写排版。英雄变化只需传入不同 `FactionKey`，原画资源由卡牌自身提供。

## 可查看场景

`CardFaceShowcase.tscn` 使用项目现有的臂铠、野猪、审判之锤定义，分别展示小型、中型、大型卡；原画是此前生成的示例图裁片，没有引用 `ref/` 中的图片。正式卡牌仍需在创建 ViewModel 时传入自己的原画。

示例价值从项目 `CardValueCalculator` 读取。效果数值只作为展示输入，不由卡面 UI 计算战斗结果。
