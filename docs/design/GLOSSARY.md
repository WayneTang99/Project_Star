# GLOSSARY.md
Project_Star 术语表。统一术语定义，避免歧义；**新增/变更需求时，术语必须引用本表定义**，新概念先在此登记再提需求。

## 使用约定

- 提出新需求时，先用本表已有术语描述；若需引入新术语，先补充到本表（含英文名与中文名），再写需求。
- 术语命名一律用英文（PascalCase 类名 / StringName key），中文为展示或口头用语。
- 已定术语不允许在需求中另行改名（如把"卡牌"叫"牌"、把"轮次"叫"波次"）。

## 卡牌描述用语

### 卡牌文案规范

适用于全部卡牌的正式词条、能力生成文案、悬停详情、右键预览和图鉴；文案调整不改变实际筛选条件或结算顺序。

1. **定语在前，卡牌在后**：按“归属 → 数量／选择方式 → 位置／区域／存活条件 → 尺寸 → 元素 → 种族／类型标签 → 能力分类 → 卡牌”组织，省略没有配置的条件。例如“己方1张小型光属性人类卡牌”“敌方随机1张存活战场小型卡牌”。不要把限制拆到“卡牌”后面。“其他”须明确排除此卡牌还是本次发动者。
2. **条件在前，结果在后**：先写“当……后／每……／若……”，再写目标和动作。触发者的尺寸、元素和标签放进触发主语；“且／或”按真实筛选关系使用。卡牌数量用阿拉伯数字与“张”，不以“件”代指卡牌。 回响必须在同一句中完整表达方向、触发者尺寸／元素／标签、具体状态与次数限制；效果目标用“此卡牌／该卡牌／明确的另一张卡牌”区分，不能用“符合条件”“指定一侧”等占位表述。
3. **详情显示规则和当前加成，卡面显示最终数值**：固定数值效果的详情可以直接显示数值。英雄等级、生命比例、护甲、价值、累计消耗、最大生命百分比等特殊机制同样接受适用的属性、光环、宝石等加成；详情保留计算来源、比例／倍率、取整、消耗、触发和持续范围，并以“机制公式 + 当前加成”展示，例如“造成敌方最大生命值的20%伤害 + 30”，不能把公式替换为最终结果。加成位于公式内部时按真实运算顺序标注，不能为统一格式改变含义；零加成显示“+ 0”，负加成显示“− 数值”。卡面将同一效果的机制结果与加成合并，读取当前战场、等级／宝石预览或回放时刻冻结的最终伤害、护甲、治疗、状态施加量等，包含实际生效加成与倍率。卡面优先使用真实上下文和已知属性；脱离对局时己方生命比例默认100%。仍缺少必要依据时显示0，不显示机制文字、公式或百分比；详情继续解释规则并标明当前参与计算的属性数值。
4. **分级与当前等级分开**：Definition的斜杠数值从初始等级依次到4级；运行时详情只展示当前所选等级的规则，卡面只展示该快照数值。界面不显示其他等级数组、原始key或内部类型名。
5. **词条按实际时机命名**：冷却结束自动触发用“发动”，响应事件用“回响”，此卡牌被摧毁时触发用“亡语”，持续求值用“光环”；拾取、出售、交易、开战、轮初、升级、历战、凯旋、消耗、任务依照本表定义。回响充能至零产生的主动发动及其多重不再触发回响，之后独立正常发动仍可触发。
6. **范围与持久性明确**：区分己方／敌方、战场／备战、相邻／任意、自身／其他、单个／全部。“永久”仅指跨战斗保留的对局变化；本场成长、消耗、失效撤销和重要排除条件按实际规则说明，不为简短而省略。
7. **详情信息完整**：显示尺寸、全部实际标签及元素，套装单独标识；主动卡牌用独立“冷却／数值／秒”区域突出当前有效完整冷却，无主动能力时隐藏。卡面不堆放规则正文。原文不存富文本，颜色由表现层统一添加。
8. **中文、目标与卡牌引用**：描述不使用冒号，不显示英文内部属性名或英文时长单位；词条与正文以空格分隔。每个动作按实际效果明确目标，不再统一添加“己方英雄”等目标前缀，避免与效果自身的目标重复；持续状态写明“此卡牌／该卡牌获得数值秒状态”。召唤、转变和获得指定卡牌等效果中的具体卡名统一以“【卡名】”标注，表现层整段金色加粗，不能将卡名内部的元素或属性词拆开着色；身份筛选标签继续使用“[标签]”。

正式数据维护见[内容数据规范](CONTENT_DATA.md)，界面布局见[UI系统](UI_SYSTEM.md)。

卡牌描述中的固定表述，含义与战斗机制绑定，写需求时须按此语义使用。

| 术语 | 英文 | 定义 |
|---|---|---|
| 此卡牌 | This Card | 描述所在的那张卡本身（自指） |
| 该卡牌 | That Card | 前文刚提到的卡牌（指代前文出现的对象） |
| 永久 | Permanent | 对局内属性/本体的持久变化；战斗结束时消失/回滚的变动不能称为永久。永久摧毁 = 直接从玩家卡池删除该卡牌 |

## 词条与标签

标签：卡牌的分类，无特殊效果，用于搜索或筛选等使用。词条：按生效机制组织卡牌效果描述，每条保存 StringName 词条 key 与说明文字；一张卡可包含多个词条，同类词条也可重复。词条本身不执行能力。

| 术语 | 英文 | 定义 |
|---|---|---|

| 中型 | Medium | 型号标签，卡牌尺寸中 |

### 词条

发动、回响、光环、任务的 key 分别为 `keyword.activate`、`keyword.echo`、`keyword.aura`、`keyword.quest`；名称由 `CardKeywords` 统一维护。光环“持续生效”指来源有效期间，并不自动表示跨战斗永久保留。

| 术语 | 英文 | 定义 |
|---|---|---|
| 发动 | Activate | 卡牌冷却结束后自动触发的能力（主动/周期触发） |
| 亡语 | Deathrattle | 此卡牌被摧毁时触发的效果，词条 key 为 `keyword.deathrattle`，与回响分开显示；每次真实摧毁结算一次，具体效果以卡牌为准 |
| 回响 | Echo | 响应自身或其他卡牌发动所产生的事件的被动效果，具体事件条件由该卡说明限定，文案为“回响：当……后，……”。描述分类不改变既有战斗回响事件的连锁限制；拾取、出售不属于回响。例：`回响：当相邻人类卡牌获得疾速后，该卡牌攻击增加10。` |
| 己方卡牌状态获得回响 | EchoOnAlliedCardStatusGained | 己方存活战场卡牌实际获得正时长疾速、迟缓或禁锢后触发，以受影响方筛选，不要求由己方施加；回响产生的状态不再触发回响 |
| 光环 | Aura | 始终生效或依据当前状态持续求值的效果，文案统一为“光环：……”；效果范围与失效条件按该卡定义 |
| 拾取 | Pickup | 获得此卡牌时结算的对局效果；词条 key 为 `keyword.pickup` |
| 出售 | Sell | 出售此卡牌时结算的对局效果；词条 key 为 `keyword.sell` |
| 消耗 | Consume | 使用后摧毁此卡牌；默认仅本场战斗生效，下场战斗恢复，不永久移出卡池；词条 key 为 `keyword.consume` |
| 开战 | Opening | 战斗开始时触发一次的效果；词条 key 为 `keyword.opening`。发动时机、来源及目标遵循能力定义 |
| 升级 | HeroLevelUp | 己方英雄每升一级触发一次的对局词条，key为 `keyword.upgrade`；不指卡牌合并升级，是否在备战区生效由能力定义指定。 |
| 轮初 | RoundStart | 每轮开始边界触发一次的对局效果；词条 key 为 `keyword.round_start`。默认来源须位于战场区，轮中获得不补发本轮效果 |
| 交易 | Trade | 响应获得（含购买、奖励与合并获得）或出售其他卡牌的交易事件的效果；具体条件由卡牌说明限定。词条 key 为 `keyword.trade`；获得此卡牌自身的效果仍归为“拾取”，只有出售此卡牌自身的效果归为“出售”，不属于战斗回响 |
| 历战 | AfterBattle | 战斗结算后生效的效果；词条 key 为 `keyword.after_battle`，是否要求参战及胜负条件由定义限定 |
| 凯旋 | Victory | 参战获胜后生效的效果；词条 key 为 `keyword.victory`，只在来源满足参战及获胜条件时结算 |
| 被动 | Passive | 非主动发动能力的底层总称；正式描述按开战、回响、光环、交易、历战、凯旋归类，不改变既有能力与事件规则。`keyword.passive`保留供通用内部夹具使用 |
| 召唤 | Summon | 按卡牌说明在战斗中创建临时卡牌；词条 key 为 `keyword.summon`。召唤物仅本场战斗存在，不进入对局卡池，不触发拾取或合并 |
| 任务 | Quest | 卡牌实例独立累计条件进度，达标后解锁可复用能力；备战区可累计，能力仅在来源卡牌位于战场区时生效。例：`任务：胜利一场战斗后，攻击力 +100` |

## 战斗描述用语

战斗规则中的固定表述，含义与战斗机制绑定，写需求时须按此语义使用。

| 术语 | 英文 | 定义 |
|---|---|---|
| 日蚀时间 | EclipseTime | 进入后双方按配置曲线受到伤害，优先扣护甲，护甲不足时再扣生命；卡牌继续正常发动 |
| 日蚀进入触发 | PassiveOnEclipseStart | 全场唯一一次进入日蚀时触发；自然或提前进入共用，重复进入无效果，备战与摧毁来源不触发 |
| 寂灭时间 | ExtinctionTime | 强制结束战斗；若双方同时死亡，判玩家胜 |

| 插画 | Illustration | 实体属性集只读身份中的原画资源标识，技能使用独立方形图标原画；不影响玩法数值，由表现层加载纹理 |
| 卡牌图鉴 | CardCatalog | 局外浏览全部正式卡牌、支持等级、基础数值与词条效果的只读界面，不创建对局或卡牌实例 |
| 套装 | CardSet | 卡牌只读身份中的可选归属；按战场区不同卡牌 key 计数，达到的多个阈值效果累计生效 |

| 怪物胜利触发 | PassiveOnMonsterVictory | 己方击败怪物后结算的对局能力，参战来源及等级按开战冻结，不包含PvP |
| 技能 | Skill | 独立于卡牌的能力载体，不占棋盘格；首版仅含被动能力，可由任意内容入口获得，实例属于当前对局 |
| 技能图鉴 | SkillCatalog | 局外浏览全部正式技能、图标原画与各支持等级效果的只读界面，不获得技能或执行能力 |
| 战场区 | Battlefield | 参战卡牌区域；战斗时只有战场区卡牌生效 |
| 备战区 | Bench | 备用卡牌区域；不参战，但被动可能生效、可能影响战场数值 |
| 遭遇 | Encounter | 玩家回合中的选项，从若干遭遇中选一个执行；类型含商店、怪物战、PvP、其他。与领域事件（Match Event / Combat Event）区分 |
| 遭遇英雄资格 | EncounterHeroEligibility | 遭遇在排程前对当前英雄的准入条件；允许英雄key列表为空时不限制，非空时仅所列英雄可遇到；与商店商品的职业筛选独立 |
| 探险类遭遇 | Exploration Encounter | 可选项遭遇的内容子类，共用固定选项与加权结果机制；沿用其他遭遇（Other）的排程和结算，具体奖励与风险由各自 Definition 配置 |
| 加权结算结果 | WeightedEncounterOutcome | 确认遭遇选项后按正整数权重抽取一个效果，区别于进入事件时决定展示选项的加权展示槽 |
| 回合 | Turn | 时间推进的最小递进单位，每回合派发一个遭遇（通常为三选一）供玩家选择执行 |
| 轮 | Round | 由固定数量回合组成的阶段（8 回合为 1 轮）；第 4 回合三怪物遭遇、第 8 回合固定 PvP 遭遇，声望扣量与轮次相关 |
| 对局 | Match | 从选英雄到胜负结束的完整过程；一局游戏 = 一个对局 |
| 战斗 | Battle | 对局中的一次自动战斗；怪物战与 PvP 都是战斗 |
| 怪物 | Monster | 本质是预设英雄；战斗逻辑不为怪物单独写 |
| 导师 | Mentor | 独立的技能传授内容，可由遭遇包装或其他入口访问；按自身筛选规则提供最多三个不同技能，选择一个获得。导师等级决定技能等级，遭遇访问时遭遇等级决定导师等级 |
| 对局胜利 | MatchWin | 第 8 回合 PvP 胜利累计满 10 次 |
| 对局失败 | MatchLoss | 声望 ≤ 0 |

## 战斗机制

| 术语 | 英文 | 定义 |
|---|---|---|
| 主动能力 | ActiveAbility | 卡牌冷却结束后自动发动的能力 |
| 被动能力 | PassiveAbility | 响应战斗事件触发的能力，与主动能力触发方式不同 |
| 魔法消耗 | ManaCost | 发动能力所需魔法；魔法不足则不发动，免魔法卡牌消耗为 0 |
| 累计魔法消耗 | ManaSpent | 己方英雄在本场战斗中成功发动能力时实际支付的魔法总量；每场战斗重新从 0 计算，多重的额外发动不重复支付也不重复累计 |
| 被动光环 | PassiveAura | 无冷却、无魔法消耗的持续能力；来源位于战场区且未被摧毁时生效，来源失效后立即移除 |
| 战斗开始触发 | PassiveOnBattleStart | 战斗开始事件后、首个逻辑 tick 前触发一次的被动能力；多个来源按稳定顺序进入能力队列 |
| 充能 | Charge | 使卡牌当前剩余冷却立即减少指定时长，最低减至 0；减至 0 时可在当前 Tick 发动 |
| 修复 | Repair | 恢复本场被摧毁的卡牌，保留其数值、能力及已有触发历史，主动能力从完整冷却重新开始；原位置被存活卡牌占用或已永久摧毁时不可修复 |
| 转变 | Transform | 本场战斗内替换目标卡牌的身份、标签、属性和能力，保留实例标识、位置及等级；清除原属性加成、状态及冷却倍率，从新卡完整冷却重新计时，取消原卡已排队能力；战后恢复原卡 |

## 英雄属性

英雄属性分两类：**对局资源**（跨战斗保留）与**战斗状态**（每场战斗开始重新生成，战斗结束不保留）。

对局资源：

| 术语 | 英文 | 定义 |
|---|---|---|
| 金钱 | Wealth | 对局经济资源，跨战斗保留 |
| 经验 | Experience | 对局成长资源，跨战斗保留；每回合开始获得1点（含第1回合），每10点升一级并扣除10点，保留余数；怪物奖励同样参与升级 |
| 等级 | Level | 英雄等级，跨战斗保留 |
| 声望 | Reputation | 对局结局评价资源，跨战斗保留 |

战斗状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 生命 | Health | 英雄当前生命值，归零该方战斗失败 |
| 最大生命 | MaxHealth | 生命上限 |
| 濒临死亡 | First Lethal Damage | 每场战斗己方英雄首次受到足以使生命归零的伤害，救援在伤害结算后、死亡判定前立即生效；寂灭强制终止不属于伤害 |
| 护甲 | Armor | 抵扣伤害的属性 |
| 灼伤 | Burn | 每 0.6 秒造成当前灼伤值的伤害（优先扣护甲），伤害后减少 1，最低为 0；伤害与衰减使用同一周期 |
| 灼伤施加量加成 | BurnBonus | 卡牌每次施加灼伤的额外量，固定量、属性量或百分比向下取整后累加一次，再应用发动狂暴；区别于英雄已受到的灼伤 |
| 中毒 | Poison | 每 1 秒造成当前中毒值的伤害（无视护甲），本场战斗内持续生效、不衰减，重复施加累加 |
| 隐身 | Stealth | 英雄限时战斗状态，阻挡卡牌、技能及套装直接攻击造成的生命和护甲伤害；不阻挡灼伤、中毒、日蚀，也不阻止状态施加。重复施加时长累加，按0.1秒Tick衰减，不跨战斗保留 |
| 生命再生 | HealthRegen | 每 1 秒恢复生命（取整） |
| 魔法 | Mana | 魔法当前值，供发动能力消耗 |
| 最大魔法 | MaxMana | 魔法上限 |
| 魔法再生 | ManaRegen | 每 1 秒恢复魔法（取整），上限为最大魔法 |

## 卡牌属性

卡牌属性同样分**对局资源**（跨战斗保留）与**战斗状态**（每场战斗开始重新生成，战斗结束不保留）。

元素属性：

| 术语 | 英文 | 定义 |
|---|---|---|
| 属性 | Element | 卡牌的元素归类；每张卡牌必须拥有 1～2 个属性 |
| 无属性 | General | 十种属性之一，不表示空值或缺省状态 |
| 火属性 | Fire | 火元素属性 |
| 水属性 | Water | 水元素属性 |
| 风属性 | Wind | 风元素属性 |
| 土属性 | Earth | 土元素属性 |
| 电属性 | Lightning | 电元素属性 |
| 木属性 | Wood | 木元素属性 |
| 冰属性 | Ice | 冰元素属性 |
| 光属性 | Light | 光元素属性 |
| 暗属性 | Dark | 暗元素属性 |
| 属性字段 | ElementKeys | 卡牌只读身份字段，保存 1～2 个不重复的元素属性 key；属性顺序不影响含义 |
| 无阵营 | Neutral | 卡牌内容归属之一，表示不专属于任何英雄；与元素属性中的无属性无关 |
| 自动获得 | AutomaticAcquisition | 无需玩家点击的卡牌获得；产生时立即尝试放入战场区或备战区，两区已满则不创建卡牌 |

对局资源：

| 术语 | 英文 | 定义 |
|---|---|---|
| 等级 | Level | 卡牌等级，影响价值等数值，跨战斗保留 |
| 价值 | Value | 卡牌当前价值（出售回补按此值），跨战斗保留；获得时先按初始价值折半，再结算获得时价值加成；合成时补新旧等级标准获得价值差额，保留已有成长 |
| 收入 | Income | 英雄的对局属性；每轮开始时转化为等量金钱，默认值为5，同一轮只结算一次 |
| 合并升级 | Merge Upgrade | 获得同 key、同等级且低于4级的卡牌时，消耗新获得项并提升已有实例等级；可以连续发生 |
| 对局加成 | PersistentBonus | 卡牌跨战斗保留的加成 |
| 冷却倍率 | CooldownMultiplier | 对局内永久保留的十进制比例，范围0.00～1.00，默认1.00；有效冷却乘此值，重复百分比缩减累乘，升级保留 |
| 解锁记录 | UnlockRecord | 卡牌对局内的解锁记录 |

战斗状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 临时加成 | BattleBonus | 仅本场战斗生效的加成，战斗结束不保留 |
| 治疗加成 | HealingBonus | 增加已有治疗效果的治疗量，每次治疗累加后受最大生命限制；不影响魔法恢复和生命再生 |
| 冷却 | Cooldown | 主动能力的完整冷却时长，在固定增减及所有倍率计算后最低1秒；不限制充能到0、倒计时速度或多重的0.2秒间隔 |
| 战斗回放 | BattlePlayback | 一次结算后按冻结时间点与日志顺序播放，暂停、倍速或跳过均不再次计算或发奖 |
| 疾速时长 | HasteDuration | 冷却速度 ×2 的持续时长 |
| 中毒施加量加成 | PoisonBonus | 仅增强已有中毒施加能力的每次施加量，基础量计算后累加，不改变卡牌价值等公式输入 |
| 疾速时长加成 | HasteDurationBonus | 卡牌每次施加疾速的永久基础时长增量，内部按0.1秒Tick存储，在目标标签倍率前累加；不是当前剩余疾速时间 |
| 迟缓时长 | SlowDuration | 冷却速度 ×0.5 的持续时长 |
| 飞行 | Flying / IsFlying | 布尔战斗状态；新受到的迟缓、禁锢时长减半，按Tick向下取整；不影响已有剩余时长或疾速 |
| 狂暴 | Berserk / IsBerserk | 布尔战斗状态；自身发动的伤害及施加的中毒、灼伤量增加20%，向下取整，不重复放大周期伤害 |
| 禁锢时长 | ImmobilizeDuration | 冷却停止的持续时长 |
| 被摧毁 | Destroyed | 战斗内是否被摧毁；若为永久摧毁，战斗结束后该卡牌从卡池移除 |
