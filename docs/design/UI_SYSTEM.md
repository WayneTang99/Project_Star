# UI 系统规范

日蚀进入效果在详情显示为“回响：进入日蚀时间时……”，提前进入在发动行显示全场仅一次；套装详情沿用2／3／4件阈值行，显示永久冷却缩减、生命上限与当前生命等量增长及日蚀伤害倍率。HTML原型与原生格式化共用该展示语义，不解析展示文本执行玩法。

本文描述当前已实施的界面边界与卡面规范。玩法见 [游戏规则](GAME_DESIGN.md)，业务实现见 [架构](../engineering/ARCHITECTURE.md)，待办见 [当前计划](../planning/IMPLEMENTATION_PLAN.md)，验收见 [人工验收](../quality/MANUAL_ACCEPTANCE.md)。历史迁移方案由 Git 保存。

更新时间：2026-10-15。卡面套装、多重图标、简化详情及右键等级／宝石预览已按HTML同步原生；完整页面视觉验收仍未完成，见 [专项待办](../planning/UI_HTML_PARITY_TODO.md)。UI设计先改[HTML原型](prototypes/game-16x9.html)，再按当前方案同步项目；明确只改HTML时止于原型。可复用[流程技能](../../.codex/skills/project-star-ui-html-first/SKILL.md)。

用户确认的[统一HTML](prototypes/game-16x9.html)已用于接入出售卡面跟随、出售区域、左下经济区、右上菜单及属性专属色，范围见[计划](../planning/UI_UNIFIED_PROTOTYPE_PLAN.md)。按随后反馈，卡面效果底板按各自专属色渐变、价值底板为金色，数字统一浅象牙白，属性色保留于图标和详情；原卡面构图保持。

## 属性配色

元素徽标采用独立配色：无属性灰、火朱红、水深蓝、风浅薄荷绿、土棕褐、雷鲜黄、木草绿、冰青、光白底金色符文、暗深紫。风与木通过明度和冷暖区分，水与冰通过深浅及蓝／青区分；光不再使用黄色底。风符文使用共用`art/ui/card-face/wind-rune.svg`卷风形，23px徽标内显示19px符文、2.5px设计笔画，HTML与原生按同一资源缩放。其他符文保留原形，雷使用深棕符文、光使用金色符文，保证浅底对比。

属性色独立于等级框、元素和棋盘皮肤，不随皮肤资源替换改变。卡面效果与价值数字统一使用浅象牙白`#FFF2CD`，效果底板按对应专属色的52%→28%明度做渐变，保留原细边；价值底板为金币色的35%明度。各属性底板保留区别，位置与尺寸不变；效果图标仍使用对应属性色。详情只为相关词语及数值着色，次数、件数、等级等数字不套属性色，不整段染色。

生命及魔法资源条的填充也使用对应专属色：生命翡翠绿、魔法紫色，按65%→40%明度做渐变，条上数值统一浅象牙白。己方英雄与敌方摘要共用这套规则，保持原条形尺寸及当前值／最大值比例。

## 菜单与经济区

布局硬约束：HTML与原生战斗界面同时保留上方敌方战场与下方己方战场，不得使用备战区替换或遮挡敌方战场。战斗准备与回放期间禁用备战入口；战斗外可展开备战区，复用上方阶段区域，关闭后恢复阶段内容，己方战场不移动。拖拽悬停备战入口350毫秒展开，离开抽屉区域150毫秒收起以露出当前阶段，支持跨区摆放和宝石镶嵌。

金钱与每轮收入固定于左下，顶栏保留品牌及轮回合轨迹，右上为菜单。菜单包含继续游戏、设置、卡牌图鉴、技能图鉴与放弃对局；选角、对局和结算均可浏览图鉴，查询不推进随机或触发卡牌效果。返回／Escape恢复原页面和菜单入口焦点，Tab限制在当前弹窗。

放弃对局需二次确认，取消保留原对局。确认经Presenter校验当前对局身份并调用应用用例，保存失败终局摘要后返回选角；旧确认或交易动作不能作用于新对局，无进行中对局时禁用放弃。

设置只提供分辨率，当前仅有默认砂石主题，不显示配色或皮肤选择入口，也不读取旧的蓝色配色配置。应用后15秒内确认才保存，取消、Escape、超时、隐藏或保存失败恢复原尺寸和位置。超宽窗口仍以16:9画布居中留边。

拖拽使用原CardFace的展示快照与缩放，保留抓取偏移，源卡淡化。摆放显示青色落点，失败为红色；棋盘边缘24逻辑像素内释放取消，不出售。移出棋盘与缓冲区后才进入琥珀出售态，250像素宽的提示跟随鼠标，显示卡名、金额和正式出售效果；Escape取消，合法释放通过既有交易用例和金额／身份校验。

宝石商店的紧凑宝石器件位于固定阶段框内，以宝石图形、名称和费用展示，完整效果及失败原因保留在悬停与拖拽提示。落点优先判定摆放和镶嵌，失败的镶嵌不退化为出售。出售反馈不占桌面区域；本次镶嵌完成后仍可移出棋盘出售卡牌。

## 宝石商店与套装

卡牌详情的套装区按当前HTML使用独立分隔线、套装标题及右侧当前件数；阈值以“件数／效果／状态”三列显示，已生效为绿色，长效果只在中列换行。顶部显示套装名称标签，有套装的无属性卡不再重复显示“无”；元素仍在页脚完整展示。效果由正式能力和冻结英雄等级生成，常驻套装增益省略光环前缀，己方英雄目标省略重复文字。选中卡牌的出售按钮显示“确认出售 · 获得 N 金币”，原有出售门控保持。

宝石商店读取本次访问的等级、费用、宝石候选及操作条件；只生成实际砧板数量，不补重复候选。砧板展示名称、追加发动效果、费用和可用／已完成状态，当前正式内容见 [Gems](../../scripts/Content/Gems/) 与 [宝石商店Definition](../../scripts/Content/Encounters/GemShopEncounterDefinition.cs)。无发动、无空孔、余额不足或过期请求提供明确原因，失败保留卡牌与金钱；镶嵌使用首个空孔，一次访问最多成功一次。孔位填色和详情中的宝石名称、说明跟随同批快照，不能按孔序号伪造已镶嵌状态。

英雄套装入口按当前战场不同卡牌key显示件数、各阈值说明及未达成／已生效状态；备战不计数，达到的阈值累计展示。正式内容见 [Sets](../../scripts/Content/Sets/)，UI不计算经验、生命贡献或战后奖励。规则与生命周期见 [套装规则](GAME_DESIGN.md#套装)。

## 默认砂石皮肤与材质分层

当前只有默认砂石主题。棋盘皮肤入口为 `art/ui/skins/bronze-sandstone.tres`，对应表现层 `BoardSkin` 的TableFrame、BoardTrack、TableSurface、PortraitMount与SurfaceEffect。纹理与装饰材质不包含布局、容量、槽位、交互权限或玩法数据；更换资源经MatchShell.ApplyBoardSkin接入。固定布局与输入矩形由MatchShell维护，换肤不重建卡牌、不修改快照或随机状态；现有验证比较纹理和材质替换前后的控件矩形。

默认皮肤以独立台面／桌沿背景、细砂岩颗粒、透明头像金属底座组合。黄铜斜面反光、桌体厚度、凹槽顶部暗边与底部反光、卡牌投影及底边厚度分别叠加；图标、数字、卡面和按钮保持独立清晰。生命与魔法填充在金属框内缩4像素，避免遮住边缘。头像遮罩按控件局部坐标生成，不能用原画AtlasTexture的UV判定圆形。HUD图标直接取自当前HTML符号，不用文字替代。验收见[本次同步记录](../quality/UI_HTML_NATIVE_SYNC_2026_10_15.md)。

## 数据流与所有权

玩家输入 → MatchPresenter → 应用用例 → Result / Snapshot → MatchPageViewModel → MatchShell.Render。

| 所有者 | 职责与生命周期 |
|---|---|
| `MinimalPlaytest` | 组装服务、资源与控件，连接和释放订阅；渲染帧只推进播放游标 |
| `MatchPresenter` | 当前页面、对局引用、商店/事件访问句柄、批次版本、操作门控与反馈；通过应用层读写业务 |
| `MatchPageViewModel` | 同一次刷新取得的只读身份、数值、操作条件与失败原因；不传可变 Session |
| `MatchShell` / 子视图 | 排版、控件、焦点、提示、浮层与输入意图；Render 不执行用例 |
| `BattlePlaybackPresenter` | 播放游标、暂停、1×/2×和反馈；只消费冻结的战前身份、事件与状态快照 |

战斗召唤物由冻结记录投影为临时卡面及战场放置，包含名称、等级、词条、属性与召唤反馈；战前画面尚无召唤物，播放到召唤后出现。已摧毁卡牌的位置被再次召唤使用时，按召唤事件顺序替换旧卡的展示放置，保留旧卡的摧毁记录，避免卡面重叠。回放不向对局库存或棋盘写入，战后正常快照不包含召唤物。

领域对象拥有金钱、棋盘、卡牌、奖励和对局进度。Presenter 持有访问句柄，不复制一份可变业务数据。技能、套装和奖励列表使用英雄详情浮层；结算页同时展示待领图卡并复用同一领取入口，任务使用卡牌详情，不增加对局流程状态。

操作成功或失败后统一刷新，HUD、棋盘、详情、商品与按钮来自同一批快照。预览、鼠标移动和 Resize 只改变表现状态，不重抽商品、不推进随机、不执行交易。实体失效、换页、重开和退出时清除过期选择、提示、拖拽与播放，释放订阅；动态按钮替换前解除旧连接。

## 页面与操作

| 页面 | 上层内容 | 允许的主要操作 |
|---|---|---|
| 英雄选择 | 已注册英雄 | 选择英雄创建新局；双棋盘隐藏 |
| 卡牌图鉴 | 全部正式卡牌及支持等级 | 搜索卡名、标签或效果，按归属、尺寸、元素、初始等级、套装筛选，保留四维排序，选择卡牌与预览等级；返回原页面 |
| 技能图鉴 | 全部正式技能及方形图标原画 | 搜索技能名或效果，按归属、初始等级筛选，切换支持等级；返回原页面 |
| 遭遇选择 | 实际候选组 | 选择遭遇、调整构筑；不跳过未选择回合 |
| 商店 | 商品卡面、报价、售罄与刷新费用 | 购买、刷新、出售、离开；拒绝旧报价批次 |
| 普通事件 | 动态选项、成本与结果 | 成功执行一次后继续；失败保留上下文 |

探险类遭遇复用普通事件的原画与动态选项组件，显示随机金币区间、各结果概率及本次访问等级的奖励。指定卡牌名称从正式卡牌目录读取。HTML页面状态入口提供暮歌丛林与流沙地带的代表预览，不执行正式奖励结算。
| 战斗准备 | 敌方英雄与棋盘 | 调整构筑、开始战斗；空战场允许开始 |
| 战斗播放 | 冻结阵容与战斗数值 | 暂停、倍速、跳过；业务操作和棋盘修改被门控 |
| 战斗结算 | 结果、资源差额、允许领取的奖励 | 查看、领奖、继续；对局进行中可调整棋盘 |
| 对局结束 | 胜负与累计结果 | 返回选角、领取用例允许的末局奖励；棋盘只读 |

按钮状态不能代替服务校验。出售意图携带对局身份、卡牌、等级与金额，提交前重新核对；奖励索引结合列表版本，失败保留待领项。购买/合并/放置与从棋盘出售都是应用层完整事务。

遭遇选择使用横向原画图卡，整张图卡支持鼠标和键盘选择，底部浅色区域显示名称与一句用途简述；悬停及焦点显示外部描边。事件页面在内容区左侧显示原画、右侧显示动态选项及其效果说明，离开时隐藏。简述来自正式 Definition，选项说明由通用效果与当前英雄等级生成。原画资源与等级来自只读快照，渲染不重抽候选。图卡左上角保留等级文字，悬停说明商品等级上限，等级由下面约定的边框颜色表示。

卡牌、技能、遭遇、怪物、导师及其等级详情使用独立2px等级框：1银灰、2蓝、3紫、4橙、5红。遭遇图卡同时显示等级文字，阶段插画读取本次遭遇／导师访问等级；技能图鉴切换等级时同步更新预览和详情框，已获得技能与待领技能也保留等级标识。英雄肖像与等级牌不使用等级色。等级框不随主题、悬停、焦点和战斗状态变色；容器浮层的描边跟随真实外边界，不参与正文排版。商店等级继续用于商品上限，其他遭遇等级不套用商店规则。

导师遭遇复用普通事件页面，显示本次最多三个技能的名称、授予等级和能力说明，完整说明可通过悬停读取。候选来自导师访问的冻结快照；刷新和重绘不重新抽选，成功选择后技能侧栏同步更新并允许继续。空池显示没有可传授技能并允许继续。导师遭遇等级同时决定本次导师及授予技能等级，测试入口的等级覆盖遵循同一关系。

`Playtest.tscn` 测试入口统一把商店、事件、怪物战及 PvP 遭遇设为4级，图卡和阶段标题使用橙色晶体。覆盖值由入口注入应用排程，写入候选快照；商店生成与刷新按候选中的4级上限处理，刷新费用8金币。正式 Definition 和普通排程仍使用原等级；商品使用定义初始等级，怪物卡组保留原配置；显式随遭遇等级发放的奖励使用本次4级访问等级。

## 布局与输入

2026-10-10已迁移获批16:9排版。逻辑画布1600×900，CanvasItems等比伸缩，非16:9居中留边；顶部保留原栏和导航，怪物页左侧原摘要在上、英雄组件在下，右侧敌方战场、己方战场、备战区从上到下固定排列。普通阶段左上显示英雄，原标题区移入右侧阶段面板左段，商品／选项位于其右。两侧装饰以整个画布定位并先于面板绘制。整页不滚动，现有商品、选项、详情及开发工具保留局部滚动。复用原卡面、资源条、按钮、字体和主题；卡牌比例及英雄不使用等级色的约定不变。

准备与播放同时显示怪物摘要和完整敌方10格棋盘，不再通过展开／返回切换摘要与阵容；敌方卡牌位置、等级、空格及临时召唤继续来自快照和冻结回放投影，棋盘只读。商店、遭遇、事件及结算沿用现有组件，阶段操作仍分发原应用意图。

开始界面右上角提供“设置”，复用现有主题的显示设置弹窗，提供1280×720、1600×900、1920×1080、2560×1440；超出当前屏幕可用范围时拒绝预览；无边框使用屏幕完整尺寸，带边框使用工作区。应用后15秒内确认保留才写入user://display.cfg；取消、Escape、超时、离页及销毁恢复原窗口尺寸与位置，保存失败也恢复。重新启动读取有效已保存设置，验证／截图入口跳过自动加载用户配置。显示设置不创建或修改对局。

右上菜单提供卡牌图鉴与技能图鉴入口，选角和对局内均可浏览。打开图鉴时隐藏英雄预览与详情；返回或Escape恢复原页面并把焦点移回菜单入口。技能图鉴复用局外浏览布局：全宽可滚动的方形原画列表，悬停复用局内技能提示，右键或Shift+F10打开原画、等级选择和完整说明浮层。默认显示初始等级，只列出定义支持的等级，切换后效果数值来自该等级能力快照；不赋予技能卡牌的尺寸、元素、价值或宝石孔。搜索匹配技能名、归属和各等级效果，与归属和初始等级筛选组合；空结果隐藏旧详情，筛选和返回不获得技能或执行能力。

`SkillCatalogQuery`捕获正式目录并生成只读条目，由入口注入`SkillCatalogView`，新增正式技能自动进入图鉴。`SkillItemView`从`SkillSnapshot.Illustration`加载方形图标，图鉴及已获得技能详情共用；缺图夹具使用占位图，效果关键词复用详情配色。

选角页采用左侧英雄名册、中央完整方形原画、右侧身份和初始属性的三列布局。名册显示头像、姓名和称号，选中项以天蓝描边及勾选标记强调；点击名册或方向键切换只更新本地预览，原画使用150毫秒轻过渡。右侧称号与姓名分开显示，初始属性可折叠，数值来自Definition投影的只读`HeroSelectionDetails`，不在视图硬编码。确认按钮固定在右侧底部，显示“以姓名开始冒险”；点击确认或Enter才通过既有用例创建对局，图鉴等外部控件持有焦点时不会抢占按键。刷新按key保留当前浏览英雄，名册内容未变时复用按钮与焦点，替换后解绑旧按钮。布局按可用宽高收敛，宽屏内容居中，名册超出高度时纵向滚动。选角期间隐藏棋盘和英雄侧栏，展示区域占满顶部栏下方；进入对局后恢复英雄侧栏与右侧三段内容。英雄插画来自只读身份与快照，缺图时仍可选角并显示姓名。

圣骑士选角原画使用8秒循环待机：上身每4秒随呼吸起伏，头颈整体轻摆，持锤手与整把锤同步移动，发梢、披风与衣摆延迟摆动。现有原画通过轮廓蒙版进行局部形变，面部不参与布料波动，背景建筑与方形边界保持稳定。锤头和胸前圣徽叠加呼吸圣光、柔和光晕与短光芒，光源跟随人物位移；少量金色光点缓慢上浮，光效避开面部与原画边界。同页刷新保留播放进度，打开图鉴或隐藏选角页时暂停，返回继续；切换至圣骑士时从头播放。动效仅用于中央选角原画；名册保持静态，对局英雄小头像使用原画中的脸部取景。六位现有英雄分别设置取景，显示区域裁切不修改原画，选角中央继续展示完整原画。

圣骑士选角配音为成熟、有气魄的中文男声，包含“圣光引领着我们！”与“重拾战锤家族的荣耀！”。前者语速接近自然、音调略低、语气坚定有力；后者语速稍快、语气更激昂。点击名册中的圣骑士或方向键切换到他时，两句以相同概率随机播放一句，允许连续抽到同一句；重复点选先停止上一句，再重新抽取并从头播放，单个播放器避免叠加。初始展示和只读刷新不自动触发，也不重新抽取。随机独立于对局与战斗状态。切至其他英雄、清空名册、打开图鉴、隐藏选角页或退出时停播；返回选角页后再次主动点选才播放。音频使用随项目打包的本地资源，游戏运行时无需语音生成服务。

新增英雄默认同时生成并接入原画，维护规则见 [内容数据规范](CONTENT_DATA.md#英雄)。英雄原画使用方形构图，面部保持清晰以适应选角预览与侧栏头像；图片本身不包含文字、卡框或UI。

右上菜单提供“卡牌图鉴”。打开后覆盖当前内容，全宽为可滚动的全卡列表，取消固定右侧详情栏；悬停与键盘焦点复用局内卡牌提示，右键或Shift+F10打开局内同款卡牌详情及等级／宝石只读预览；卡面保持小/中/大型比例。第一行搜索匹配卡名、归属、标签及词条效果并显示结果数量；第二行提供归属、尺寸、元素、初始等级、套装五个筛选条件及排序字段、升降序按钮。筛选与搜索取交集，默认五项均为全部；套装选项从正式卡牌快照的SetKey收集，以套装展示名显示，选定后只列出该套装成员，刷新与关闭重开保留仍有效的套装选择；双元素卡包含所选元素即可匹配，初始等级按正式Definition判断，不受详情预览等级影响。排序可选归属、尺寸、元素、初始等级四个维度：默认归属排序依次比较归属（无阵营、圣骑士、小魔女、冒险家、机械师、潜行者、熊猫人）、初始等级（1到5）、尺寸（小、中、大），归属筛选菜单使用相同顺序；降序反转这三个维度。单独尺寸排序按小、中、大，元素按通用、火、水、风、土、雷、木、冰、光、暗，双元素再比较第二元素，初始等级按数值；同组按卡牌key稳定排列。刷新关闭旧悬停提示，关闭再打开保留筛选和排序条件；空结果隐藏旧详情。详情等级仅列出正式定义支持的等级，默认显示初始等级；切换后同步更新卡面、该等级当前数值、冷却、魔法消耗及价值。说明按通用能力生成，另列套装阈值；不推算任务解锁后的身份或对局加成。列表与详情浮层分别滚动，效果关键词复用现有配色。详情打开时Tab限制在浮层，Escape先关闭详情，归还条目焦点；再次Escape返回原页面。返回按钮或Escape恢复原页面；选角时保留原先浏览的英雄，关闭后键盘焦点回到菜单入口。

图鉴由入口调用`CardCatalogQuery.Capture`，把正式目录投影为只读条目与等级快照后注入`CardCatalogView`。查询不创建实体、执行拾取/出售/任务效果或推进随机；新增正式卡牌自动进入目录。皮肤与动效尚未实现，后续接入独立预览区，玩法定义继续作为数值和词条来源。

可选项遭遇的加权结算结果在确认前显示各分支概率，说明从通用效果生成并使用本次访问等级；植物奖励同时注明尺寸。加权说明每行组合最多两个结果，多行按钮使用13px字号，使小窗仍能同时显示奖励与怪物风险。进入怪物分支后使用既有战斗准备、回放和结算页面；无符合当前轮次且同等级的怪物时显示提示并允许继续旅程。

卡面以底边中央的菱形逐个显示宝石孔：金色描边与深色凹槽表示空孔，明亮宝石渐变填充表示已镶嵌，多个孔横向居中排列，零孔隐藏。卡面不显示孔字、数量文字或宝石名称；悬停提示和详情逐孔列出空孔、宝石名称及说明。等级由整张卡框颜色表示。商店报价显示定义孔数及空孔，棋盘与回放读取卡牌冻结快照。宝石商店中央展示实际宝石砧板，每个砧板包含宝石色、名称、说明和镶嵌价；拖放目标接受己方棋盘卡牌，由应用预检决定是否允许松开镶嵌。失败原因直接显示在砧板，取消拖拽不扣费。完成后全部砧板显示已完成并禁用，刷新按钮读取剩余次数与费用，离开商店始终可用；只展示实际宝石，不显示第三种占位砧板。

顶栏显示品牌、轮次及八回合轨迹，标记当前访问回合，第4/8回合带怪物战/玩家对战图标及说明；右上为菜单，金币与收入固定于左下。访问商店、事件、战斗准备/回放/结算时保留进入前的轮回合，返回遭遇选择后才展示领域已推进的下一回合，避免访问第1回合商店却标成第2回合；下方英雄侧栏固定在左，右侧三段共用同一内容宽度：

| 区域 | 内容 |
|---|---|
| 英雄侧栏 | 肖像、姓名、称号与等级、生命/魔法、技能/套装/奖励入口；底部经验、声望与胜场 |
| 右侧阶段区 | 等级色的阶段插画与操作；敌方战场 / 遭遇 / 商店 / 事件 / 结果互斥切换 |
| 右侧中排 | 战场，10格 |
| 右侧下排 | 备战，10格 |

生命、魔法、经验使用语义图标和数值资源条，经验为当前经验／10，悬停可读资源名称。声望、胜场使用图标配数字。构筑阶段生命显示当前上限、魔法显示初始魔法，回放阶段双方生命、魔法、护甲、灼伤和中毒均读取冻结战斗快照；左上怪物摘要与左下英雄显示相同语义的持续伤害徽章。回放反馈在侧栏底部显示近期事件，不覆盖经验与等级。

阶段内容位于1600×900逻辑画布的(240,250)～(1360,480)，己方棋盘固定在(277,500)～(1323,730)，备战展开复用上方棋盘矩形。两侧棋盘宽1046、高230、内边距13、格间距0，十格每格102×204；小／中／大型卡面分别保持1:2／1:1／3:2，拖拽共用SlotPitch。英雄HUD以(800,825)为头像中心；生命与魔法条在左右两翼，护甲与“+再生”位于生命条两端，成长摘要与技能位于各自资源条下方；经济与备战入口为对称100×74器件。主操作固定在右侧(1392,462)，不重复显示离店按钮。最低窗口1280×720，覆盖1920×1080、2560×1440、2560×1080与缩回；整页不滚动，浮层与图鉴独立滚动。

对局主题的中文使用 Microsoft YaHei 常规字重，品牌和关键数值使用 Georgia，按角色设置字号、字重与字距。HTML 提取的 SVG 图标和渐变位于`art/ui/html/`。对局视口关闭HDR 2D，使半透明UI按与浏览器一致的sRGB方式合成；截图读回不再额外做线性转sRGB。

商店商品横向排列，同高卡面显示等级和元素，右侧显示卡名、冷却、价格和点击提示；价格为说明，整张商品卡左键／Enter／Space提交购买。合并资格、禁用原因和报价版本仍来自应用查询；售罄或重复点击不重复扣款，失败保留商品。横向商品区跟随键盘焦点滚动。结算页和英雄奖励浮层中的卡牌同样直接点击／键盘获取，携带原奖励索引和版本；技能奖励保留领取按钮。右键打开放大预览，不提交交易；拖拽松手不同时提交交易。阶段插画区显示等级文字、标题和说明，下方为刷新、离开及“•••”开发折叠入口；左侧英雄区提供主要继续／开始操作。左上战斗摘要保留暂停、倍速、跳过，右上敌方阵容直接显示，不再折叠。

棋盘共用横向格位标尺，小/中/大型占1/2/3格；标题只显示区域名及已用/总格数，空格序号弱化显示在底部。`BoardZoneView`按EntityId复用独立`CardItemView`，卡面与外层点击区均覆盖完整占格区间，不留额外内缩缝隙。独立组件也同时按宽度和可用高度约束格宽，保持1:2/1:1/3:2比例；落点和预览使用实际格高。外层接收鼠标与拖拽，CardFace装饰忽略鼠标。

卡牌悬浮动画使用相对居中位置的6px偏移，Tween只更新偏移量；刷新及缩放后的位置由同一布局方法计算。鼠标离开恢复尺寸适配后的居中位置，不把大型卡牌的绝对Y清为0。

拖拽载荷只携带 MatchId、EntityId、抓取格偏移和占格数。预览调用只读 `PreviewPlaceCard`，原卡保持原位；提交重新计算完整 PlacementPlan。取消、失败、越界、只读区域和旧对局载荷均不改变模型。点击/键盘移动沿用相同应用入口。

## 战斗回放

`ResolveBattleForPlayback` 一次完成结算，返回双方战前身份、BattleResult 与玩家结算后快照。播放只消费 BattleResult.States 与原事件日志；同 Tick 保持记录顺序，EventCount 指向日志前缀。治疗、护甲、魔法、状态衰减、冷却、充能和摧毁都读取真实记录，不由 UI 补算。

自然结束或跳过只切换到结算页，不重复发奖；暂停、倍速不改变结果。战前身份使永久摧毁的卡牌仍能完成回放。强调 Tween 只影响装饰，重复强调先停止旧 Tween，换页与退出释放。

发动条与剩余秒数位于原卡面内，不改变原画、元素、效果、价值和宝石孔。进度读取冻结的剩余／总冷却（半Tick单位，每20单位为1秒）；多主动能力沿用最慢冷却比例。疾速为青蓝流光、迟缓为灰褐斜纹，同时存在保留两项标识并使用正常进度色；禁锢显示暂停及锁链，读取已停住的进度。飞行／狂暴显示独立标识和轻微原画强调；摧毁原画灰化，隐藏有效进度。修复按CardRepairedEvent与冻结状态恢复原画及完整冷却，反馈显示“已修复”，召唤／修复的占格变化按事件顺序投影。发动内侧短闪光、充能跳字来自回放事件，备战与非战斗页清除状态层。

灼伤徽章显示0.6秒周期，中毒显示1秒周期；状态为0时隐藏。亮度脉冲及扣血／护甲吸收跳字只读取DamageDealtEvent中的StatusOrigin、HealthDamage和ArmorAbsorbed。事件来源在战斗结算层冻结，同Tick灼伤／中毒分别反馈；表现层不按Tick、生命差或周期重新推算伤害。暂停冻结反馈年龄，倍速与跳过仍只推进记录游标。

双方英雄状态区显示“隐身”及冻结快照中的剩余秒数，为0时隐藏；提示说明其阻挡攻击伤害，不阻挡灼伤、中毒和日蚀。回放反馈显示隐身获得、到期与避开攻击，暂停保持原剩余时间；表现层不重新计算隐身或免伤。

## 卡面与详情

CardFace 只读取 CardFaceViewModel，显示身份、等级、插画、元素、效果和价值；详情、标签和冷却显示在外层。商店、棋盘、奖励共用卡面和 CardDisplayAdapter。插画缺失时显示统一占位并保留真实身份。

### 固定版式

以高度 400 为基准，各尺寸维持同高：

| 尺寸 | 卡面宽 × 高 | 比例 |
|---|---:|---:|
| 小型 | 200 × 400 | 1:2 |
| 中型 | 400 × 400 | 1:1 |
| 大型 | 600 × 400 | 3:2 |

- 卡面隐藏卡名，不设置通栏标题与底栏；卡名由悬停和详情读取。整张卡框使用等级颜色（1银灰、2蓝、3紫、4橙、5红），不显示左上等级菱形或卡面等级文字。底边菱形仅表示宝石孔，多个孔居中并排，零孔隐藏。
- 底图：原画覆盖卡牌宽高的100%，等比填满并按整张卡牌裁切；不同尺寸和效果数量不再改变插画区域。不拉伸原画。
- 所有信息和边框都作为overlay叠加在插画上；2px等级色外框及同色65%透明度的1px内描边包围5px内缩插画，底部遮罩改善数值可读性。效果格使用对应语义颜色的渐变，数值使用 Georgia；价值牌渐变仍待对齐。
- 属性圆徽23px贴右上角，距右边和上边7px；双属性以4px间隔并排，通用属性用银灰圆徽。宝石孔由8px正方形旋转45°形成菱形，正方形间距7px，整组在底边中央排列；650px及以下视口使用6px正方形与5px间距。
- 底部左侧：魔法消耗大于0时优先显示紫色魔法图标与“−消耗量”，复用魔法配色，与恢复魔法的正数区分；零消耗不显示。其余效果图标与数值按传入顺序纵向堆叠，每项独立格子，行高25px、间距3px、底边留7px。数值默认15px，窄视口13px；宽度用实际字体测量。只显示卡面容纳的前几项，完整规则与公式由详情承载；极小商品的长数值边界仍待验收。
- 同一能力中累计魔法护甲与自身护甲加成合为一个护甲徽标：零加成显示“累计魔法”，非零显示“累计魔法+数值”；回放读取两项冻结施加量之和。正式能力组合及战斗计算不变。
- 底部右侧：价值图标和当前价值放在左边斜切的独立区域，靠右下对齐；与左侧效果格留出间隔。
- 不显示冷却、描述、标签等其他字段。

外框由等级决定，桌面配色和归属不覆盖等级色。字体与布局对所有卡牌相同；不改变信息位置、字号、徽章大小或整张卡牌的插画覆盖范围。悬停轮廓使用等级色，选中和键盘焦点轮廓向外绘制以保留等级框。基准卡面、紧凑棋盘、商店与奖励共用同一规则。

### 可查看场景

`CardFaceShowcase.tscn` 使用正式臂铠、野猪、审判之锤定义，分别展示小型、中型、大型卡。正式卡牌原画以各Definition的Illustration为准；资源验证检查全池路径与纹理加载。

原画生成与更新使用项目 Skill `project-star-card-artwork`（`.codex/skills/project-star-card-artwork/SKILL.md`）。当前采用细致明亮的手绘日式奇幻画风；生成前读取卡牌 Definition 的尺寸，分别按小型1:2、中型1:1、大型3:2构图，并核对输出实际比例。

原画以突出主体为第一优先级，缩小到卡面后仍须清楚醒目；允许主体边缘出画，不为追求完整而把主体缩得过小。在此基础上尽量通过动作、视角、斜向构图、层次或光影对比增加画面张力，背景与特效不能压过主体。同一职业保持相近的线条、比例、材质、光照、渲染细致程度与主色调，不同职业尽量有明显色调区分。生成前优先查看同归属的已认可卡牌及英雄原画；元素色与单卡情绪可作局部变化，无阵营卡牌按主体采用自然色彩。职业尚无稳定基准时先说明配色建议，不把临时方案当作已认可色板。

圣骑士军团以白色＋金色建立主色调和军团识别，不要求整幅及所有材质都变成白金。钢铁、皮革、动物和环境保留自然色；按身份、装备、旗帜功能或效果，在合适位置使用少量红、蓝、紫及其他辅助色，形成层次和单卡区别。避免大面积绿色衣料和旗面继续承担军团主配色，不把要求扩大成禁止一切其他颜色；破誓者等特殊身份保留必要暗色及局部效果色。

上述主体、张力、风格与职业色调要求同样适用于英雄及技能原画；英雄继续采用方形构图和清晰面部，技能继续保证小图标可辨认。检查结论区分明确的尺寸/识别问题与可优化的审美建议，不把静态物品、场景卡或局部元素色变化一律判为不符合。

非英雄的人物卡牌尽量弱化鲜明、可辨认的个体脸部特征，可按身份使用头盔、面罩、兜帽阴影、闭眼、发光眼或光效处理；通过装备、动作、轮廓和职业效果保持主体辨识，不用精细脸部肖像承担辨识。英雄保留鲜明角色面貌；动物、植物及物品不套用人物遮脸规则。

天使形象统一佩戴覆盖双眼的布质眼部遮罩，可按服装使用白色与金色细节；闭眼、发光眼或头盔不能替代眼部遮罩。正义天使、小天使及呈现天使形象的飞升者均遵循此约定；不强制天使穿戴头盔或盔甲，姿态与服装按单卡身份设计。

战矛、法杖、扫帚等细长物品作为主体时，应看清整体形制及主要两端，不只显示矛头、杖头等局部。通过斜向构图、适度透视、明暗分离和简化背景兼顾完整与醒目，不以极端裁切代替主体突出；此要求不强制人物全身或巨龙翼尖完整入画。

原画接入和重绘证据见 [当前验收](../quality/MANUAL_ACCEPTANCE.md)；新增内容逐张检查实际比例、主体辨识与资源加载，不沿用历史批次数量判断当前卡池。

插画属于卡牌属性集的只读身份字段 `CardIdentityAttributes.Illustration`，由对应卡牌 Definition 声明。对局快照和商店报价快照传递该字段，`CardDisplayAdapter` 按路径加载并缓存纹理，再交给卡面显示；不维护按卡牌 key 匹配图片的列表。插画为空或资源不存在时使用共用占位图，组件展示中的缺图示例只覆盖展示快照。

示例价值从项目 `CardValueCalculator` 读取。效果数值只作为展示输入，不由卡面 UI 计算战斗结果。

己方战场备战卡面通过战斗层只读预览显示当前有效光环及英雄等级对应的数值；预览不发动、不推进随机或写回实例，备战区仍显示自身属性。战斗卡面读取该时刻冻结的施加量，包含条件倍率、狂暴和宝石比例，伤害显示扣敌方护甲前的数值，治疗显示可提供的治疗量；尚未知对手时保留依赖对手的比例说明。卡面左上角显示套装名称；多重使用专属青色图标和次数，与攻击、护甲共用效果行，当前次数大于0时显示，回放和刷新同步更新。详情另列“多重”词条。

卡牌详情由`CardDisplayAdapter.Rules`根据通用能力与当前冻结数值生成统一短文案，不展示初始值、其他等级数值或通用机制说明。出售、历战成长等规则读取快照中的正式配置；任务单独展示。`DescriptionEntries`保留用于检索等内部用途。详情显示套装名称、当前战场不同key件数、各阈值效果及未达成／已生效状态；商品和图鉴无对局时件数为0。紧凑卡面只显示关键图标与当前数值。

悬停和棋盘选中详情共用`CardDetailsContent`，禁用卡牌引擎Tooltip路径：13px标签／24px卡名／49px冷却圆徽、18px正文、等级／元素／价值底栏。浮层通常440px宽，小窗口收敛宽度，长正文局部滚动；悬停正文透过鼠标命中，选中后可操作，宝石及当前属性从底部展开。右键或Shift+F10打开`CardPreviewView`：大卡面占主要视觉区域并保持尺寸比例，旁侧提供正式支持等级、实际孔位的宝石选择、还原及简化详情。`CardPreviewQuery`在副本中保留成长并重算数值，不改变实例、资源或随机状态；无主动能力的宝石选项禁用。关闭／Escape归还来源焦点，Tab限制在预览内；来源奖励浮层保留，关闭预览不会交易。

独立的“成长任务”区逐项显示条件、当前／目标次数、进度条、完整奖励和进行中／已解锁文字。目标、条件和奖励读取随卡牌快照冻结的正式任务定义，进度按`StringName`任务key关联实例或回放状态；不解析展示文本，不按列表位置匹配。商品无实例进度时显示0，回放使用该时刻的冻结进度，临时召唤或变身卡牌同样携带任务定义。超额进度保留真实次数，进度条限制到目标；无任务隐藏区域。完整奖励包含解锁能力、追加发动效果、冷却、元素和标签变化；正文可滚动，不增加任务奖励领取按钮，保持达标自动解锁。

详情标题使用Microsoft YaHei粗体及2px字距，圆徽数值使用Georgia粗体，正文增加行间留白并突出关键词和数值；标签先显示尺寸，再显示其余标签及元素。背景按实际面板尺寸绘制130°渐变，蓝色桌面仍保留HTML详情的配色。正文与展开区共用窗口高度预算；同卡刷新只更新快照，保持位置、淡入进度及展开状态；固定详情在页面滚动／缩放时保持可见，失效卡牌及换页仍关闭。

上述详情尺寸与字体以屏幕像素为单位，不随16:9主画布等比放大：标准分辨率下440px宽，49px圆徽与24px标题保持一致。2px边框加20px正文留白共22px；邻接卡牌留16px，显示时从下方6px位移在120ms内淡入。真实分辨率变化及恢复后重新计算锚点、翻转和边界，等级框、关闭按钮一同换算；刷新和固定不重启动效或累计位移。以可读性、完整悬停／按下／焦点反馈与实际操作为验收目标，HTML原字号保持原样，不要求逐像素追齐字体栅格或阴影边缘。

详情仅显示当前属性，按实际能力用途展示：只有具备发动能力才显示冷却，伤害效果读取攻击属性时才显示攻击。不能仅按数值是否为0判断，真实攻击为0仍需显示；辅助卡牌的占位攻击、无发动能力的冷却不显示。

飞行／狂暴由布尔战斗快照提供，为真时出现在卡牌战斗状态和详情中，为假时不显示；不显示层数，也不将它们混入攻击等数值属性。回放按记录刷新并保留旧快照，非战斗默认无这些状态。

战斗状态层位于CardItemView，不改变CardFace本体版式；发动光带、剩余秒数、独立状态徽章和双方持续伤害反馈的现行规则见上文“战斗回放”。状态层跟随卡面居中位置及悬浮偏移，输入仍由外层处理。

非战斗且棋盘可编辑时，己方战场／备战卡牌可拖至顶部信息栏和上方商店／遭遇区域出售。该区域只在有效己方卡牌拖拽时显示出售提示，悬停查询现值回补，松开直接出售并结算出售效果。Escape取消或释放到目标之外不出售；敌方卡牌、旧对局载荷、战斗回放及终局不可出售。提交时再次校验等级、金额和出售条件，失败保留卡牌及资源；原详情确认出售入口保留。

仅详情描述、任务条件／奖励和套装效果中的属性词语与关联数值使用统一属性配色；标签、尺寸、元素在这些描述内以金色方括号标识。标题、顶部标签、底栏和按钮不做自动关键词着色或添加方括号，顶部元素标签用“火”“水”等简称，不带“属性”。“生命再生”“魔法再生”优先按完整词语识别；发动、回响、光环、多重等词条用青色`#83CEC6`，次数、件数、等级等数字保持正文色。原始文案不存富文本标记。

“轮初”词条使用 `keyword.round_start`，详情与短描述沿用其他词条的青色文字；HTML原型提供独立示例入口。

拾取能力使用现有青色“拾取”词条，详情显示获得／合并后的当前等级奖励规则。跨英雄冷却光环与随机奖励说明包含“无阵营”，HTML原型提供伪装面具示例。

按钮反馈读取原按钮的悬停、按下、键盘焦点及禁用状态；主要按钮区分普通、悬停与按下样式，插画按钮的高亮和按下遮罩绘制在插画上方。动态遭遇、英雄、技能、菜单、设置和图鉴按钮使用相同规则；鼠标移出恢复，键盘激活仍提交原有操作一次。卡牌鼠标悬停及键盘焦点共享上浮和等级色发光，按下有可见反馈，离开焦点恢复。禁用按钮保持既有原因及操作门控。

按钮光标仅在类型变化时更新。取消选择时没有选中项则不重绘页面，避免重建商品导致已关闭详情被重新悬停打开；Escape关闭后仍可通过重新悬停或键盘焦点查看。
