# Project_Star 卡牌数据表

本文档记录正式卡牌内容数据，供设计、实现和审查使用。玩法规则以 `docs/GAME_DESIGN.md` 为准，术语以 `docs/GLOSSARY.md` 为准；代码中的具体 `CardDefinition` 是运行时数据来源。

## 1. 字段约定

| 字段 | 含义 |
|---|---|
| CardKey | 卡牌唯一 `StringName` key |
| 归属 | 英雄阵营 key；`neutral` 表示无阵营，不限制其他英雄使用 |
| 尺寸 | Small / Medium / Large，分别占 1 / 2 / 3 格，并自动生成尺寸标签 |
| 元素 | 1～2 个元素属性；`General` 表示无属性，不表示空值 |
| 额外标签 | 尺寸标签以外的卡牌标签 |
| 初始等级 | 默认创建、商店报价和普通获得时使用的等级 |
| 支持等级 | 该定义实际提供的等级；未提供的等级不能创建 |
| 初始价值 | 商店购买价格及折半前价值 |
| 描述 | 卡牌的具体功能；数值按等级顺序书写 |

等级数据按 `等级: 数值` 书写，例如 `3: 6秒 / 4: 5秒`。`—` 表示没有该项。

## 4. 内容维护约定

新增或修改正式卡牌时必须同步更新本表，并检查：

1. CardKey 全局唯一，使用 `StringName`。
2. 归属 key 对应已有英雄阵营或 `neutral`。
3. 元素包含 1～2 个合法值。
4. 初始等级包含在支持等级中。
5. 1～4级可以按内容需要只提供部分等级；5级只能由定义显式提供，不能通过同级合并产生。
6. 能力、出售奖励和获得时加成使用通用定义，不在应用服务中硬编码卡牌专属判断。
7. 数值或描述变更后同步更新 Godot 内验证入口。
