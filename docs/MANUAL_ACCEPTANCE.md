# Project_Star 当前试玩人工验收

本清单对应 `Playtest.tscn` 与 `Main.tscn` 的现有实现。执行前运行 `dotnet build`，然后在 Godot 4.7 .NET 中打开项目。

## 规则验证入口

1. 运行 `Main.tscn`，确认第 1～9 步验证列表全部显示通过；记录失败项及错误信息。
2. 点击“返回试玩”，确认能进入 `Playtest.tscn`。

## 试玩闭环

1. 选择英雄，确认显示第 1 轮第 1 回合、金钱 **999**、收入 5，战场区和备战区为空。
2. 选择商店，确认商品按钮显示等级、名称、大小、阵营、元素和价格。购买一张卡，确认金钱扣除且卡牌进入战场区；继续购买同名同级卡时，确认可合并升级。
3. 确认己方战场、备战及敌方战场的已放置卡牌显示等级、名称、大小、阵营和元素。点击己方卡牌及目标格移动，确认位置更新；放置失败时确认提示且原位置保留。
4. 选择普通事件并领取一个选项，确认奖励或属性变化显示在界面，随后可以进入下一回合。
5. 第 4 回合选择怪物遭遇，确认敌方卡牌显示、战斗可开始，结算画面显示伤害与胜负，继续后能进入下一回合。
6. 第 8 回合进入 PvP，确认结算后的声望或胜场变化及轮次推进。重新开始一局，确认上一局卡牌、棋盘和遭遇历史不保留。

## 技能验证

1. 在 `Main.tscn` 的规则验证列表确认“技能使用独立实例并按同级规则合并”和“空战场的被动技能可触发且回响不会连锁”通过。
2. 首版正式内容尚无技能奖励入口；试玩界面暂不能手动获取或展示技能，取得技能需由内容入口调用 `AcquireSkill`。

本清单记录手动验收步骤；尚未执行的项目不得标记为已通过。
