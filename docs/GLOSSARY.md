# GLOSSARY.md
Project_Star 术语表。统一术语定义，避免歧义；**新增/变更需求时，术语必须引用本表定义**，新概念先在此登记再提需求。

## 使用约定

- 提出新需求时，先用本表已有术语描述；若需引入新术语，先补充到本表（含英文名与中文名），再写需求。
- 术语命名一律用英文（PascalCase 类名 / StringName key），中文为展示或口头用语。
- 已定术语不允许在需求中另行改名（如把"卡牌"叫"牌"、把"轮次"叫"波次"）。

## 卡牌描述用语

卡牌描述中的固定表述，含义与战斗机制绑定，写需求时须按此语义使用。

| 术语 | 英文 | 定义 |
|---|---|---|
| 此卡牌 | This Card | 描述所在的那张卡本身（自指） |
| 该卡牌 | That Card | 前文刚提到的卡牌（指代前文出现的对象） |
| 永久 | Permanent | 对局内属性永久变化，非战斗临时；战斗结束时消失/回滚的变动不能称为永久 |
| 发动 | Activate | 因 CD 读取完毕而触发的能力（主动/周期触发） |
| 当...时 | When... | 非 CD 读取的被动触发（事件驱动），与"发动"互斥 |

## 战斗描述用语

战斗规则中的固定表述，含义与战斗机制绑定，写需求时须按此语义使用。

| 术语 | 英文 | 定义 |
|---|---|---|
| 坍缩时间 | CollapseTime | 进入后双方同时扣血，卡牌继续正常发动 |
| 寂灭时间 | ExtinctionTime | 强制结束战斗；若双方同时死亡，判玩家胜 |

## 战斗基础术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 英雄 | Hero | 玩家在战斗中的主体；唯一有血量的单位，无攻击能力，血量归零该方失败 |
| 卡牌 | Card | 战斗中的能力载体；无血量，放在战场区，可被 debuff 或摧毁 |
| 战场区 | Battlefield | 玩家放置参战卡牌的区域；战斗时只有战场区卡牌生效 |
| 备战区 | Bench | 玩家放置备用卡牌的区域；不参战，但被动能力可能生效、可能影响战场数值 |
| 事件 | Event | 对局中的选项，每回合选一个执行；类型含商店、怪物战、PvP、其他 |
| 对局 | Match | 从选英雄到胜负结束的完整过程；一局游戏 = 一个对局 |
| 对局胜利 | MatchWin | 第 8 回合 PvP 胜利累计满 10 次 |
| 对局失败 | MatchLoss | 声望 ≤ 0 |
| 战斗 | Battle | 对局中的一次自动战斗；怪物战与 PvP 都是战斗 |
| 怪物 | Monster | 本质是预设英雄；怪物战即英雄 vs 英雄，战斗逻辑不为怪物单独写 |
| 参战实体 | Combatant | 参与战斗的实体：双方英雄、双方战场卡牌、玩家备战卡牌 |
| 混合方案 | HybridState | 不深拷贝实体副本；对局内持久状态战斗内不动，战斗内临时状态单独存储、结束丢弃 |
| 永久性质 | Permanent | 战斗内标记的变化（如永久摧毁卡牌），战斗结束时收集并应用到本体；永久摧毁 = 直接从玩家卡池删除该卡牌 |
| 第 8 回合 PvP | Round8PvP | 每轮最后一回合固定为异步玩家对战事件；其胜利次数累计满 10 次即对局胜利 |

## 战斗机制术语

| 术语 | 英文 | 定义 |
|---|---|---|
| 时间推进层 | TimeAdvanceLayer | 高频只推进时钟的层，步长可配置，不做逻辑 |
| 逻辑结算层 | LogicResolveLayer | 低频做所有逻辑结算的层，步长可配置且为其他步长基准 |
| 主动能力 | ActiveAbility | CD 到了自动发动的能力；入队 depth = 0 |
| 被动能力 | PassiveAbility | 监听事件、事件发生触发的能力；入队 depth = 上一层 + 1 |
| 能力队列 | AbilityQueue | 主动与被动共用的队列，按入队顺序处理，深度上限防无限链式 |
| 深度上限 | MaxChainDepth | 链式触发的层数上限（可配置），超过不入队 |
| 能量消耗 | EnergyCost | 能力发动前在 CanActivate 中检查；通过则扣能量再执行，免能量为 0 |
| 坍缩 | Collapse | 双方同时扣血开始的时间点；扣血按配置曲线，卡牌继续正常发动 |
| 寂灭 | Extinction | 强制结束战斗的时间点；双方同时死亡判玩家胜 |
| 结束原因 | EndReason | 战斗结束原因（EnemyHeroDied / PlayerHeroDied / Timeout / Surrender / Draw） |
| 战斗结果 | BattleResult | 战斗输出：Winner / EndReason / 双方幸存者 / 永久性质变化 |

## 英雄属性

英雄属性分两部分：**对局内持久状态**（跨战斗保留、战斗内不动）与**战斗内临时状态**（单独存储、战斗开始从持久状态派生初始值、战斗结束丢弃、不应用本体）。

对局内持久状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 金钱 | Wealth | 对局经济资源，跨战斗保留 |
| 经验 | Experience | 对局成长资源，跨战斗保留 |
| 等级 | Level | 英雄等级，跨战斗保留 |
| 声望 | Reputation | 对局结局评价资源，跨战斗保留 |

战斗内临时状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 生命 | Health | 英雄当前生命值，归零该方战斗失败 |
| 最大生命 | MaxHealth | 生命上限 |
| 护甲 | Armor | 抵扣伤害的属性 |
| 辐射 | Radiation | 每 1 秒触发伤害（Floor 取整、无视护甲），每 1 秒按 Floor(值/2) 衰减 |
| 腐蚀 | Corrosion | 每 1 秒触发伤害（Floor 取整、优先扣护甲），每 0.2 秒按 Floor(值-固定值) 衰减 |
| 生命再生 | HealthRegen | 每 1 秒回血 Floor(生命再生) |
| 能量 | Energy | 能量当前值，供能力发动消耗 |
| 最大能量 | MaxEnergy | 能量上限 |
| 能量再生 | EnergyRegen | 每 1 秒回能 Floor(能量再生)，上限 MaxEnergy |

## 卡牌状态

卡牌状态同样分对局内持久状态与战斗内临时状态。

对局内持久状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 等级 | Level | 卡牌等级，影响价值等数值，跨战斗保留 |
| 价值 | Value | 卡牌当前价值（出售回补按此值），跨战斗保留 |
| 对局内持久加成 | PersistentBonus | 卡牌跨战斗保留的加成 |
| 解锁记录 | UnlockRecord | 卡牌对局内的解锁记录 |

战斗内临时状态：

| 术语 | 英文 | 定义 |
|---|---|---|
| 战斗内临时加成 | BattleBonus | 仅本场战斗生效的加成，战斗结束丢弃 |
| 冷却 | Cooldown | 主动能力两次发动之间的间隔 |
| 超频时长 | OverclockDuration | 冷却速度 ×2 的持续时长 |
| 麻痹时长 | ParalysisDuration | 冷却速度 ×0.5 的持续时长 |
| 禁锢时长 | ImmobilizeDuration | 冷却停止的持续时长 |
| 被摧毁 | Destroyed | 战斗内是否被摧毁的标记；若为永久摧毁，战斗结束直接从玩家卡池删除该卡牌 |
