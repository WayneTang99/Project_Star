## 分批回归入口

内容增多后优先按批次运行，避免把全部验证压在同一帧／同一进程。当前474项按原分类拆为30批，每批最多20项；清单从当前代码生成，新增检查自动纳入。不要手工维护检查数量或只跳过失败项。

使用Godot .NET可执行文件，PowerShell 7运行：

```powershell
$godot = 'D:\Wayne\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64.exe'
# 列出当前批次；默认先构建一次
./scripts/Presentation/Verification/RunVerification.ps1 -GodotPath $godot -List
# 仅执行指定批次，可传多个key
./scripts/Presentation/Verification/RunVerification.ps1 -GodotPath $godot -Batch group-10-part-01
# 逐批执行整套回归，失败后继续汇总其余批次
./scripts/Presentation/Verification/RunVerification.ps1 -GodotPath $godot
```

可用`-SkipBuild`复用刚完成的构建；`-TimeoutSeconds`指定单批超时，默认180秒。脚本每批启动独立无头进程，崩溃、超时或引擎ERROR均记失败，超时终止本批进程树并继续下一批，不提高Godot消息队列上限来掩盖积压。
