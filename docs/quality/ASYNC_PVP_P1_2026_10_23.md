## 2. 49 项检查覆盖

| 范围 | 实际断言 |
|---|---|
| 注册 | 有效邀请注册两个不同玩家、次数耗尽拒绝、大小写重复账号拒绝、失败不消耗邀请码、并发抢最后一次邀请只有一个成功、到期邀请拒绝、非法账号和短密码拒绝 |
| 登录与身份 | 未认证拒绝、错误密码与不存在账号同一错误、大小写归一化登录返回相同玩家 ID、查询参数或伪造身份头无法切换为其他玩家 |
| 会话 | 并发续期只有一个成功、旧访问与续期凭证失效、重复续期拒绝、退出撤销两种凭证且不影响另一登录、绝对期限不延长 |
| 密码重置 | 撤销该玩家会话和续期、旧密码失效、新密码仍进入原玩家 ID |
| 到期 | 访问到期拒绝但仍可合法续期；会话绝对到期同时拒绝访问和续期 |
| 部署与恢复 | systemd 重启后访问／续期有效；切换新程序、回滚、删除本次临时旧程序后会话保留；服务账号不能写程序树 |
| 请求边界 | 非法 JSON 400、超过16 KiB请求 413、登录限流429、限流后就绪检查仍正常；响应禁止缓存 |
| 数据与日志 | 密码为 Identity 哈希格式；本次所有已生成明文密码／邀请码／访问与续期凭证未出现在 SQL dump 和账号服务 journal；数据库物理目录不在程序内 |
| 显式目录 | 程序目录充当数据目录失败；缺失持久目录配置失败 |
| 备份 | 独立恢复库的玩家数和会话数与备份源一致，指定有效会话仍归属原玩家；验证后仅删除本次恢复库 |

本次权限、请求和数据库测试不能代表不存在所有安全缺陷。账号 A/B 的身份投影隔离已测；对局、战斗结果等接口尚不存在，相关越权验证在 P2～P4 执行。

## 3. 程序与数据分离证据

- 程序 root 所有、只读；持久业务目录 `/var/lib/project-star/`、数据库 `/var/lib/postgresql/18/main/`、配置 `/etc/project-star/api.env`、journal 日志均在程序树之外。
- 测试先在 auth-02 创建会话，安装同构建的新版本并切换入口，读取原会话；随后切回 auth-02 重启，再删除自己创建的临时版本，原会话仍可读取。
- 迁移为显式命令，版本1使用事务与 advisory lock；服务启动只检查兼容版本。发布没有携带数据库。
- 备份 `/var/lib/project-star/backups/qa_02e2b34aeb40.dump`，0600。恢复到单独的临时 PostgreSQL 数据库进行行数及会话归属核对，没有覆盖正在运行的账号库。
- 尚未配置离机备份和定时保留，尚未演练真实对局数据恢复；同盘备份无法抵御整机／磁盘故障。
