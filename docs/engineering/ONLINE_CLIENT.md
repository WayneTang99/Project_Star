# Main 联网客户端：当前使用与边界

更新：2026-10-23。Main仍是唯一游戏入口。大厅右上地球图标打开“联网冒险”面板；左侧注册／登录及创建／恢复，右侧展示服务器当前阶段、报价、阵容、固定对手和结果摘要。现有大厅“开始冒险”仍是本地流程；云端旅程从联网面板内开始，两者不互传存档。

## 1. 现在可以做什么

- 邀请码注册、密码登录、退出；登录后自动读取进行中对局，同一账号重登可恢复。
- 按正式初始资源创建对局；卡牌商店选择／购买／一次刷新／离店，棋盘移动与出售确认。
- 服务器已下发的选项事件选择／结算／离开，怪物准备／结算／奖励／继续。
- 第8回合参战后查询固定PvP任务，展示真实对手／测试构筑标记、结果和待领项，处理奖励后进入下一轮。失败任务可以重试原场。
- 终局按ID读取已有结果，允许开始新局；尚无历史对局列表或主动投降入口。

面板使用简洁列表展示姓名、等级、价格、位置与结果，不将服务器展示字段重建为本地可变模型。完整棋盘卡面、技能／成长详情、拖放和战斗回放尚未接入此联网视图，不能把本地界面的回放或详情当作本场在线战斗。导师／宝石及高轮次全部可达操作仍待服务化。当前是开发联调切片，不是正式公网发布版本。

## 2. 在当前电脑连接云端

云端API继续只监听回环。用[服务器访问说明](SERVER_ACCESS.md)准备当前机器的SSH密钥及已核实的主机指纹，不复制私钥进仓库。

1. 在单独PowerShell终端运行：

   ```powershell
   ./scripts/Infrastructure/Server/OpenApiTunnel.ps1
   ```

   默认转发本机`127.0.0.1:15080`至云端回环API；保持终端运行，Ctrl+C关闭。若当前机器使用其他密钥或SSH目标，通过`-IdentityFile`／`-SshTarget`指定。脚本不会读取或输出私钥正文。

2. 正常运行项目进入Main，点击大厅右上地球图标。用已有账号登录；新账号按[账号管理命令](ACCOUNT_SERVER.md#5-管理命令)取得邀请码后，在面板注册。不要把自动验证的qa账号作为日常账号。
3. 点击“恢复旅程”读取云端；没有进行中对局时选择英雄并“开始新旅程”。关闭面板可回大厅，本次内存会话保留；关闭程序后重新登录。

客户端默认地址为`http://127.0.0.1:15080/`。以后用`PROJECT_STAR_API_URL`指定HTTPS地址；纯HTTP只允许回环，地址必须为根路径，不接受用户信息、查询参数或片段。保持系统证书验证，拒绝重定向。当前没有域名，公网HTTPS及可信代理限流仍待配置。

本轮联调已启动本机回环SSH转发，无系统自启动或公网开放；端口已被该隧道使用时不要再启动第二份。重启电脑后需重新运行上述脚本。

## 3. 会话、请求与视图

`OnlineGateway`在基础设施层持有当前会话，只通过单个门控发送请求及续期。遇401时最多轮换一次后重试同一请求，并发读取不各自轮换。续期响应丢失导致无法取得新凭证时，要求重新登录，不循环重用旧续期凭证。密码、邀请码提交后从控件清除；访问／续期凭证只在内存，尚未接系统凭证库，也不落入日志、源码或发布包。

`OnlineJourney`在应用层拥有只读快照及可空原操作。每次修改固定`requestId`和预期版本；超时、非法响应或可重试HTTP错误保留原请求，并阻止新修改。“重试原操作”完整复用原内容。409后读取当前状态，不自动把旧意图改成新版本重发。读取状态可以帮助确认进度，但不会擅自丢弃未确定请求。

同局视图只接收不低于当前版本的响应。创建时还固定原对局／版本，旧创建回执不能覆盖后来读到的另一个新局。历史PvP结果同样不能覆盖已领奖或继续后的新状态。战斗阶段标题优先使用固定的发生轮回合，不能以已推进的下一回合充当本场边界。

参战成功后约每1.5秒查询同一battleId，不由客户端提交模拟结果。关闭面板暂停自动查询；云端已提交任务继续执行。技术重试保持同一场输入，正式规则和任务契约见[PvP实现](PVP_SERVER.md)。当前仅结果摘要，没有完整回放下载协议；客户端不会从这些摘要重新模拟。

出售确认固定打开时的卡牌、对局与版本。列表中的格号为1～10，HTTP发送0～9；占格、推挤、价格、成长和合法性由服务器决定。服务器原始存档、随机状态、账号归属和任务令牌不下发给面板。

```text
Godot --headless --path . res://Verification.tscn -- --verify-online-client
Godot --path . res://Verification.tscn -- --capture-online-client
Godot --headless --path . res://Verification.tscn -- --verify-game-entry
```

真实云端客户端检查需先开启SSH隧道并构建当前程序集，再运行：

```powershell
./scripts/Presentation/Verification/RunOnlineCloud.ps1 -GodotPath '<当前Godot.NET可执行文件>'
```

此维护脚本通过SSH创建一次性邀请码，仅通过子进程环境传递，创建新的qa账号并推进其真实对局；不改写既有玩家数值、不重启云端服务，不输出密码／凭证。只在开发维护环境运行，日志在忽略的`output/online-client/`；玩家数据仍在云端独立PostgreSQL。
