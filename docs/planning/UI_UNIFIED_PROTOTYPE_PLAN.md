## 设计范围

- 保留原卡面、插画、尺寸比例、等级框、宝石孔、按钮与两种主题。怪物在上、英雄在下，怪物战场仍是主区域。
- 出售拖拽从己方战場／备战卡牌开始，达到拖动阈值后显示同卡面随鼠标移动，保留抓取偏移；上方出售区域使用原主题的纹理、描边、金币与金额提示，移入强调，移出／Escape取消，释放只出售一次。购买卡、奖励卡、敌方卡和播放中不允许出售；明确说明原因。示例仅改变预览数据。
- 金钱与每轮收入放在左下固定经济区。右上菜单包含继续游戏、设置、卡牌图鉴、技能图鉴、放弃对局；菜单和各弹窗使用同一主题、键盘焦点与Escape返回。放弃需要二次确认，明确预览结果。
- 属性使用独立于等级框的专属颜色，具体色值与使用位置见[UI规范](../design/UI_SYSTEM.md#属性配色)。卡面效果底板按各自专属色渐变、价值底板为金色，数字统一浅象牙白；图标和详情相关词语／数值使用专属色，正文不整段染色。属性色不表示元素或等级。
- 同页覆盖机制常见状态：出售有效／取消／禁用；可买／买不起／售罄／备战满；奖励未领／已领；任务0／中途／单项完成／全部完成；等级1～5；冷却／疾速／迟缓／禁锢／并存／充能／飞行／狂暴／摧毁／双方持续伤害；短／多效果／长详情；菜单／设置预览与回退／图鉴搜索与空结果／放弃确认；导师候选充足／不足三项／空候选；现行选角名册／完整原画／属性、普通事件／失败、胜负结算及终局。
- 导师以正式筛选区分：大主教1级只有捍卫，4级为捍卫与至圣斩。冲撞属于无阵营，不放进大主教池；三项选择使用单独不限阵营的排版样例，不新增正式导师或技能。
