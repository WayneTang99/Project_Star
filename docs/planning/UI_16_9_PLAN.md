## 当前排版约束

- 原版字体、字号、字距、配色、材质、边框、图标、原画、按钮、详情、任务区、商品信息及两套主题全部沿用；不再重做组件，不更换样例卡牌与原有交互。
- 以1600×900排版画布进行16:9等比适配；1280×720、1600×900、1920×1080、2560×1440使用同一结构，非16:9居中留边。画布本身不滚动，详情及预览工具保留局部滚动。
- 原顶部栏和页面导航保持在顶部。主区域左侧：怪物原摘要组件在上方，英雄原组件在下方；右侧：怪物战场／当前阶段、己方战场、备战区从上到下排列。怪物摘要与英雄在使用预览工具时保持原位置。
- 怪物页面主阶段直接显示怪物自身的完整10格战场，卡牌使用原cardHTML；怪物原肖像、状态条和播放按钮完整移到左上方，不重新设计。己方原卡牌、原画、数值、元素、效果、价值与宝石孔不变。
- 野猪的静态怪物样例沿用正式槽位：0、1为1级兽皮，2～3为1级野猪，其他为空。新增怪物样例不修改原玩家样例；生命、状态等仍沿用原版表现数据，不作为正式定义。
- 原商店、遭遇、奖励页面及购买／领取／刷新／离开、详情悬停／固定／关闭、任务进度预览、战斗状态示例、森林金／星辉蓝切换全部保留原实现。
- 卡牌与其他等级实体沿用已有等级标识；英雄不改为等级配色。

正式实现通过现有应用用例与Snapshot，不让UI修改模型；战斗表现消费冻结结果，不重新计算。新C#与.uid放在scripts/既有分层。本HTML由.gdignore隔离，运行时不引用；正式内容仍以Definition为唯一来源。
