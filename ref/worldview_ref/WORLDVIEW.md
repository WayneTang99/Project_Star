# 世界观设定总览

本文档是正式世界观的总入口，只记录文档分级、核心摘要和阅读顺序。详细设定按领域存放在专题文档中；零散灵感继续记录在 `WORLDVIEW_ELEMENTS.md`。

## 1. 文档结构

```text
WORLDVIEW.md                         世界观总览、核心摘要与待定事项
worldview/
├─ GEOGRAPHY.md                     地理、地区、世界树与根脉
├─ HISTORY.md                       创世、泰坦决战与当前局势
├─ SOCIETIES.md                     种族、组织、城邦与光明教会
└─ MAGIC_AND_ELEMENTS.md            魔法、十元素与元素泰坦
```

## 2. 收录范围

- `WORLDVIEW.md` 只记录总览、文档入口和跨领域待定事项。
- 四份专题文档按地理、历史、社会、魔法与元素分类记录正式设定。
- `WORLDVIEW_ELEMENTS.md` 只收集原子化灵感，不承担正式叙事。

## 3. 核心摘要

星球由创星者创造，并曾由水、火、土、电、风、冰、木、光、暗、无十位元素泰坦共同守护。

光之泰坦利用其他八位泰坦对自身能量的依赖，以对抗暗之泰坦为名威胁他们结盟。决战中，光之泰坦杀死八位盟友并夺取他们的能量，随后赶走暗之泰坦，但自身也元气大伤。

为防备暗之泰坦复仇，光之泰坦创立光明教会，通过控制人类心智组织军队对抗暗元素。教会控制着一个尚未命名的城邦，并借助由根脉相连的十一棵世界树，在十个已知地区之间传送兵力和维持控制。

暗之泰坦并未消亡。它计划摧毁所有世界树，切断光之泰坦的传送与控制网络，以此逼迫光之泰坦现身并完成复仇。十一棵世界树中有十棵分别对应十个已知地区，第十一棵的设定暂时留白。

人类是自然演化形成的智慧生物。星球的创造年份已经不可考；人们以泰坦决战发生年为纪年起点，将该年记为泰坦光复年 `TR1`，并使用 `TR` 年份记录此后的历史。

## 5. 待定事项

### 创世与世界规则

- 创星者的起源、目的、数量与现状是什么？
- 元素泰坦是否由创星者直接创造？
- 泰坦守护体系瓦解后，星球受到了什么影响？
- 魔法与十元素之间是什么关系？

### 泰坦与历史

- 光之泰坦以对抗暗之泰坦为名发动战争的真实动机是什么？
- 八位泰坦依赖光之泰坦能量的原因是什么？
- 光之泰坦如何夺取其他泰坦的能量？
- 暗之泰坦被赶往何处？
- 普通种族知道多少泰坦决战的真相？

### 社会与地理

- 光明教会的教义、组织结构、仪式和心智控制方式是什么？
- 教会城邦的名称、位置、统治结构和军队规模是什么？
- 第十一棵世界树位于何处、归属哪个地区或空间，又承担什么作用？
- 世界树被摧毁后会造成什么影响？
- 除人类外，其他八类种族的起源是什么？九类种族各自的文明形态、分布与相互关系是什么？

## 6. 收录原则

- 已由设计者确认的内容才能进入正式专题文档。
- 尚未确认的推测统一进入本文件的“待定事项”，不得写成既定事实。
- 零散新想法先进入 `WORLDVIEW_ELEMENTS.md`，形成稳定关系后再迁入正式文档。
- 同一条设定只在一个专题中完整描述，其他文档只保留必要摘要，避免多处版本不一致。
