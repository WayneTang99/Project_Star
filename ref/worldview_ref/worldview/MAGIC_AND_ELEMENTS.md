# 魔法与元素

## 1. 魔法

世界中存在真实的魔法。魔法的来源、施放条件、学习方式、使用代价，以及魔法与元素的具体关系尚未确定。

## 2. 十元素

世界存在水、火、土、电、风、冰、木、光、暗、无十种元素。

元素的来源、克制关系、组合规则，以及生物、魔法和物品获得元素的方式尚未确定。

## 3. 元素泰坦

| 元素 | 泰坦 | 决战后的状态 |
|---|---|---|
| 水 | 水之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 火 | 火之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 土 | 土之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 电 | 电之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 风 | 风之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 冰 | 冰之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 木 | 木之泰坦 | 被光之泰坦杀死，能量被夺取 |
| 光 | 光之泰坦 | 存活，但元气大伤 |
| 暗 | 暗之泰坦 | 存活，被赶走，正在谋划复仇 |
| 无 | 无之泰坦 | 被光之泰坦杀死，能量被夺取 |

## 4. 能量依赖

水、火、土、电、风、冰、木、无八位泰坦依赖光之泰坦的能量。暗之泰坦不依赖光之泰坦的能量。

这种依赖的成因、表现和代价尚未确定。

## 5. 光与暗

光之泰坦夺取了八位已死泰坦的元素能量，但在决战中元气大伤。

暗之泰坦没有消亡。它试图摧毁所有世界树，以切断光之泰坦的传送与控制网络，并逼迫光之泰坦现身。
