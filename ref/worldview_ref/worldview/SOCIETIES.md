# 种族与势力

## 1. 世界种族

世界中存在九类种族：

- 人类
- 龙
- 野兽
- 机械
- 植物
- 虫
- 亡灵
- 海洋
- 恶魔

除人类外，其他种族的起源尚未确定。各种族的文明形态、内部分类、分布、相互关系，以及是否都能使用魔法尚未确定。“海洋”种族的具体定义和范围也尚未确定。

### 人类

人类是自然演化而来的智慧生物。人类自然演化的具体过程、发源地区和形成文明的年份尚未确定。

## 2. 光明教会

光明教会是由光之泰坦创立、信仰光元素的宗教与政治组织。

泰坦决战后，光之泰坦因惧怕暗之泰坦复仇而创立教会，让人类代替自己继续与暗元素对抗。

## 3. 心智控制

光之泰坦通过光明教会操控人类心智。受到控制的人类被组织和训练成士兵，替光之泰坦出征。

心智控制的方式、范围、持续时间和解除条件尚未确定。

## 4. 教会城邦

光明教会控制着一个尚未命名的城邦，并在其中训练士兵。

城邦的地理位置、统治结构、人口、军队规模及居民对教会的真实态度尚未确定。

## 5. 军事与控制网络

光明教会借助十一棵由根脉相连的世界树，在十个已知地区之间传送兵力。这套网络也用于维持光之泰坦的控制。

暗之泰坦将世界树视为复仇目标，试图通过摧毁它们切断教会和光之泰坦的网络。

## 6. 公开形象与隐藏真相

- **公开形象**：信仰光元素，训练士兵并对抗暗元素。
- **隐藏真相**：光之泰坦控制人类心智，让人类替自己出征。
- **尚未确定**：教会是否公开光之泰坦的存在、如何描述泰坦决战，以及人类是否知道自己受到控制。
